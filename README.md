Bank Account Manager
A C program for managing bank account records using a random-access binary file (credit.dat). Supports creating, reading, updating, deleting, and searching account records.
Features
OptionDescription1Export all accounts to a formatted text file (accounts.txt)2Update an account balance (charge or payment)3Add a new account4Delete an existing account5Exit the program6Search accounts by last name (case-insensitive, partial match)
Data Structure
Each record stores:

Account number – integer, 1–100 (used as the record index)
Last name – up to 14 characters
First name – up to 9 characters
Balance – double-precision float

Getting Started
Compile
bashgcc -o bank bank.c
Run
bash./bank
The program will create credit.dat automatically if it doesn't exist.
Usage
On launch, you'll see a menu:
Enter your choice
1 - store a formatted text file of accounts called "accounts.txt" for printing
2 - update an account
3 - add a new account
4 - delete an account
5 - end program
6 - search accounts by last name
?
Adding an account
Choose 3, enter an account number (1–100), then enter the last name, first name, and starting balance when prompted.
Updating a balance
Choose 2, enter the account number, then enter a positive amount for a charge or a negative amount for a payment.
Searching
Choose 6 and enter a partial or full last name. The search is case-insensitive and will print all matching records.
Exporting to text
Choose 1 to write all active accounts to accounts.txt in a formatted table.
Files

Notes

Account numbers must be between 1 and 100.
The binary file uses fixed-size records, so account number directly maps to a file offset. Deleted accounts are zeroed out in place.
The search feature (option 6) uses a portable case-insensitive substring match that works on both GNU/Linux (strcasestr) and other POSIX systems.
